# Teen Mental Health Data Analysis

### 📊 Project Overview
This project analyzes social media habits and mental health metrics among teenagers. The goal of this analysis is to uncover trends regarding platform preferences, screen time, and psychological indicators. The entire workflow, from raw data processing to final visualization, was built strictly using **Microsoft Excel**.

### 🧹 Data Cleaning & Preparation
The original raw dataset was unstructured and messy. Before any analysis or visualizations could be built, extensive data cleaning was performed in Excel to ensure accuracy. Key cleaning steps included:
* **Handling Inconsistencies:** Identified and resolved missing, null, or blank entries to ensure accurate aggregations.
* **Data Standardization:** Corrected inconsistent formatting and standardized text fields across columns (e.g., ensuring platform names and gender labels were uniform).
* **Data Type Formatting:** Converted raw text strings into correct numerical and categorical formats so they could be accurately processed by Pivot Tables.
* **Structuring for Analysis:** Reorganized the raw data into a clean, tabular format optimized for XLOOKUP and dashboard integration.
### 🛠️ Tools & Skills Highlighted
* **Data Aggregation:** Built dynamic Pivot Tables to summarize large datasets.
* **Data Visualization:** Designed an interactive dashboard to visually track metrics across different demographics.
* **Analytics:** Extracted actionable insights regarding user behavior and interaction levels.

### 💡 Key Insights Extracted
* **Sample Size & Demographics:** The analysis encompasses a total of 1200 teenagers spanning ages 13 through 19.
* **Consistent Screen Time:** Average daily social media usage remains consistently high, hovering around 5 hours across all tracked age groups and both genders.
* **Mental Health Indicators:** Average scores for addiction, stress, and anxiety range between 5 and 6 for both males and females, whereas the recorded depression label averages at 0.
* **Platform Preferences:** Usage is distributed fairly evenly across the user base, with slightly higher total usage for TikTok (411 users) compared to Instagram (411 users) and users of both platforms (391 users).
